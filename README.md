## 月付比年付多花多少钱

用 Pro.TINY 算一遍最清楚：

- 月付 $12.98 × 12 = **$155.76/年**
- 年付报价 $119.99，折合 **$10/月**，一年省 $35.77，约 **23%**
- 季付 $37.99，折合 $12.66/月，比月付每月只省三毛二

季付几乎没有价格优势，它的价值在于提前锁定库存，不是省钱。年付省下的两成多，在各档位上比例大体一致。

所以判断规则很简单：

- 已经确定要用满一年、机器用途稳定 → 年付，省下的钱够再买一台 T1 小机放半年
- 只是试线路、看晚高峰表现、跑一两个月的临时项目 → 月付，多付的那 3–4 美元就是试错成本，比买错一年便宜得多

还有一类更便宜的年付机：洛杉矶不定期补货的限量款，比如 LAX.AN4.Pro.WEE（1 核 1G / 20G / 500GB @500Mbps，$39.90/年）和 T1 的 WEE（$36.90/年，1 核 1G / 20G / 1TB），折合每月三美元出头。**这两款不支持月付**，库存放出后通常很快售罄，能不能买到要看运气。

## 三条线路的月付怎么选

按用户分布选，而不是按价格从低到高排。

**移动占比高 → EB。** EB 的移动方向走 CMIN2，电信走 9929 / 58807 负载均衡。在移动宽带上，EB 的实际表现经常不比 Pro 差，价格还低三美元起。洛杉矶到国内三网的用户实测方向大致在 150–180ms，晚高峰的差别主要看回程线路是否拥塞，这一点 EB 和 Pro 都做得比国际线路好。

**电信为主、晚高峰不能掉链子 → Pro。** 三网回程都走 CN2 GIA，这段回程就是溢价的来源。如果你的访客或自己主要在电信宽带上，Pro.TINY 的 $12.98 比 EB.TINY 的 $9.99 多出的三美元，买的是高峰期不抖。

**纯国际业务、落地中转、跑脚本 → T1。** T1 走 telia、zayo、cogent 这类国际线路，没有中国大陆方向优化。为用不到的回国优化付钱是最常见的浪费，$6.90/月这一档就够用。

**要香港的低延迟 → 香港 Lite 或香港 Pro。** 香港机房延迟通常在 20–50ms，是三地里最低的，代价是价格和库存。Lite TINY $8.90/月能拿到低延迟，但没有中国大陆方向的精品路由；香港 Pro.TINY $39.90/月才是三网 CN2 GIA。

以上延迟数字来自公开整理的用户实测方向，不是官方 SLA 承诺，实际表现和所在地、运营商、时段都有关系。

东京的定位介于两者之间：T1 和洛杉矶同价（$6.90 起），Pro 走 CN2 GIA 回程，对华东华南用户常在 50–80ms 区间。

## 月付前必须知道的五条限制

**退款有流量门槛。** 官方条款写的是：购买 3 天内、且使用流量不超过 30GB，可申请全额退款；30 天内可按剩余价值部分退款。退到 DMIT 账户余额不收手续费，退到原支付渠道会扣支付网关的手续费（支付宝在退款时会返还手续费，等于免手续费）。同一产品系列退款满 3 次会被拒。月付用户尤其要注意 30GB 这条线，开通当天跑个测速、传几个 G 的文件就可能踩到，**测试前先想清楚要测什么**。

**免费换 IP 只覆盖 Pro 和 EB。** Pro 和 EB 支持约每 15 天一次的自助免费换 IP，2026 年起可以在面板里自己操作，不用提工单；超出免费次数每次 $5。Lite 系列不在这个范围，如果开出来就是不可用 IP，一般要开工单处理，且可能需要付费。买香港 Lite 的用户要把这条算进成本。

**超量限速的档位按系列不同。** Pro 的 TINY 档超量后降到 4Mbps 继续不限量；EB 多数档位落在 4–10Mbps 区间；T1 是 50–100Mbps，月初流量重置后恢复。都不断机、不额外扣费。跑大流量业务的话，T1 的限速阈值明显更宽松。

**套餐绑定机房。** 洛杉矶、东京、香港之间不能后台自由迁移，换机房等于重新买一台。如果你还在纠结放哪个机房，先月付试，别直接上年付。

**默认 SSH 密钥登录。** 不是用户名密码，第一次用要先在面板里配好密钥。这个对老手不算事，对新手是第一道坎。

支付方式支持支付宝、微信、PayPal 和信用卡，国内用户下单没有障碍。

## 常见问题

**DMIT 月付最低多少钱？**
洛杉矶和东京的 T1.TINY 都是 $6.90/月，但走国际线路，没有中国大陆优化。带回国优化的最低价是洛杉矶 EB.TINY 的 $9.99/月，再往上是 Pro.TINY 的 $12.98/月。

**月付套餐能退款吗？**
能，规则和年付一样：3 天内且流量不超 30GB 全额退，30 天内按剩余价值部分退。退款到账户余额免手续费，退原路扣支付网关手续费。具体以官网服务条款为准。

**月付可以中途升级到更高档吗？**
可以在控制面板直接升级，差价按剩余时间折算，不需要重新买。降配通常不提供。

**香港和东京为什么经常没货？**
这两个机房的资源池比洛杉矶小，补货频率低，某些时段只有部分档位能下单。看到有货不代表一直有货，这也是很多人最后回到洛杉矶的原因。

**支付宝付款按什么汇率？**
按支付渠道结算时的汇率折算成人民币，具体金额以支付页面显示为准。

**月付和年付的机器性能一样吗？**
一样，计费周期只影响价格，不影响配置和线路。
